# McElast 3X-UI KIT — 3x-easy-one

Персональный VPN/proxy-сервер на одном VPS. Установка без домена, отдельные подключения для каждого устройства и одна
HTTPS-подписка устройства. Основной профиль: **REALITY, XHTTP REALITY, Hysteria2, AmneziaWG classic и AmneziaWG 3.1**.
Windows, Linux Mint/Ubuntu, Android, iPhone/iPad и macOS.

Доступность транспортов зависит от провайдера, сети, IP VPS и методов фильтрации. После установки проверьте подключения в
Wi-Fi и мобильной сети.

## Если не хочется разбираться

| Устройство | Бесплатное приложение | Обычный режим |
|---|---|---|
| Windows, Linux, macOS | [Clash Verge Rev][clash-verge-rev] | `VPN` → `AUTO`, Rule, TUN |
| Android | [FlClash][flclash] | `VPN` → `AUTO`, Rule, VPN |
| iPhone / iPad | [Happ][happ] | проверка через прокси, ручной или автоматический выбор |
| Резерв на всех платформах | [AmneziaVPN][amnezia] | импорт AWG 3.1 или classic |

В Mihomo при проблеме: **FALLBACK → REALITY → XHTTP → HYSTERIA2 → AmneziaVPN / AWG31 → AWG classic**. В Happ выберите
подключения в том же порядке вручную, если его автоматика не восстановила связь. Не запускайте два VPN одновременно.

`AUTO` проверяет доступность и задержку примерно раз в минуту. `FALLBACK` предпочитает REALITY, затем XHTTP, Hysteria2,
AWG31 и AWG classic. В группе представлены только совместимые транспорты. Проверка одного URL не измеряет максимальную
пропускную способность и не гарантирует работу каждого сайта.

Для полного VPN включите TUN/системный VPN и проверьте обход локальной сети. Профиль рассчитан на IPv4: в клиенте
включите блокировку IPv6 либо его поддержку через туннель, затем проверьте внешний IPv4/IPv6 и DNS. Одно `ipv6: false` в
YAML не блокирует прямой IPv6 всех приложений ОС.

## Быстрый старт

1. Подготовьте чистый VPS с публичным IPv4 и доступом root по SSH.
2. Откройте SSH-терминал и выполните `sudo -i`, если вошли обычным sudo-пользователем.
3. Запустите [команду установки](#установка-сервера).
4. Сохраните итоговый вывод в защищённом месте. Проверьте `kit doctor`.
5. Создайте отдельного пользователя для каждого физического устройства.
6. Вставьте его подписку в приложение и включите VPN.

**Один физический девайс = один пользователь KIT.** Не импортируйте подписку телефона на все компьютеры.

## Требования к VPS

| Параметр | Требование |
|---|---|
| ОС сервера | Ubuntu 22.04/24.04 или Debian 12/13, systemd |
| Архитектура | x86_64 или arm64 |
| CPU / RAM | ориентир: 1–2 CPU, 1–2 GB RAM; 2 GB удобнее при установке и обновлении |
| Диск | ориентир: 10 GB, минимум несколько GB свободного места плюс место для backup |
| Сеть | публичный постоянный IPv4; прямой доступ из интернета, без CGNAT |
| Свободные порты | 80/tcp, 443/tcp, 443/udp, 51821/udp, 51822/udp |
| SSH | ваш фактический TCP-порт должен оставаться доступным |

Порты откройте также в firewall личного кабинета хостера. 80/tcp нужен для выпуска и продления сертификата на IP; домен
не нужен. Панель и внутренние порты 10443, 10444, 10446, 10460, 2097 наружу не открывайте.

## Установка сервера

Выполните от root команду установки версии **v1.0.0**:

```bash
curl -fsSL https://raw.githubusercontent.com/McElast/3x-easy-one/v1.0.0/install.sh \
  -o /root/3x-easy-one-install.sh && \
  KIT_REF=v1.0.0 bash /root/3x-easy-one-install.sh
```

Если в чистой ОС отсутствует `curl`, сначала выполните `apt-get update && apt-get install -y curl ca-certificates`.

Для установки из скачанного архива выполните `bash scripts/3x-ui.sh` из каталога проекта.

Bootstrap скачивает **один архив выбранной версии**: installer, CLI и подписка берутся из одного архива.
Версии 3X-UI и Xray закреплены; acme.sh проверяется по SHA-256.
Сторонние компоненты загружаются из официальных источников.

Для разработки допускается `main`:

```bash
curl -fsSL https://raw.githubusercontent.com/McElast/3x-easy-one/main/install.sh \
  -o /root/3x-easy-one-install.sh && \
  KIT_REF=main bash /root/3x-easy-one-install.sh
```

Для постоянного сервера используйте stable tag, а лучше конкретный commit SHA после review. Не обновляйте сервер запуском
installer повторно. Обнаружив существующую установку, он остановится без сброса БД и пользователей.
[Незавершённая установка и восстановление](manuals/INSTALL.md).

### Другие протоколы

В скачанном архиве:

```bash
bash scripts/3x-ui.sh --protocols reality,xhttp,hy2,awg,awg3
bash scripts/3x-ui.sh --protocols all
```

`recommended` и `recommended-plus` содержат оба AWG. `all` сохраняет расширенный набор; обычный WireGuard включается
только явно. `--multi-port` — схема отдельных портов, `--no-ufw` — не изменять UFW. `--panel-ssl none` — advanced режим
без публичной HTTPS-подписки, с отдельными ссылками. Обычная установка при занятом 80/tcp или ошибке сертификата
останавливается, а не выдаёт небезопасную подписку.

### Что выдаёт installer

| Строка | Что делать |
|---|---|
| Server / адрес | IP вашего VPS |
| Protocols | какие транспорты созданы; после установки подтвердите `kit doctor` |
| Panel / localhost | адрес браузера после открытия SSH-туннеля |
| SSH | готовая команда туннеля с фактическим портом панели |
| Credentials | логин и пароль администратора; сохраните отдельно |
| Subscription | подписка первого пользователя `admin`; для устройств создайте отдельные |
| QR | та же подписка для сканирования телефоном |
| configs / отдельные ссылки | персональные подключения, включая `vpn://` для AmneziaVPN |

Результат сохраняется в `/root/3x-ui.txt`, root:root, права 0600. Повторно показать: `cat /root/3x-ui.txt`. Не
пересылайте этот файл посторонним.

## Добавление устройства

На VPS:

```bash
kit user add desktop-windows
kit user add desktop-linux
kit user add phone-android
kit user add phone-iphone
```

После каждой команды появляется **своя subscription URL**. Скопируйте целиком строку, начинающуюся с `https://`
. Это основной URL для Clash Verge Rev, FlClash и Happ. Устройство получает доступ к созданным на сервере протоколам без
ручного ввода ключей.

В интерактивном терминале также выводится QR-код для сканера приложения. Он рисуется фоновыми
ячейками с белым полем вокруг. Если окно слишком узкое, KIT покажет необходимую ширину вместо
QR с переносами: расширьте окно терминала и повторите команду. При выводе в файл или pipe QR не печатается.

Чтобы показать данные повторно:

```bash
kit user link desktop-windows
kit user link phone-android
kit user link phone-android --all
```

`--all` дополнительно показывает отдельные `vpn://` -ссылки для AmneziaVPN. Выберите ссылку AWG 3.1 или classic по
подписи. Ключи AWG разных транспортов и разных устройств раздельные.

Subscription URL и QR содержат секрет подключения. **Не публикуйте их**, не отправляйте в открытые чаты, не вставляйте на
сайты конвертации подписок и не показывайте на скриншотах. Отдельного каталога публичных пользовательских конфигов нет:
данные хранятся в защищённой БД панели.

### Если потерял телефон

```bash
kit user off phone-android
```

Отключаются основная запись и связанные записи AWG этого устройства. Остальные устройства продолжают работать. При
необходимости окончательно удалите:

```bash
kit user del phone-android
```

Если подписка утекла, отключите прежнего пользователя, создайте нового с другим именем и импортируйте его URL только на
соответствующем устройстве. Простое повторное включение старого пользователя не отзывает утёкшие ключи.

## Windows — Clash Verge Rev

1. Откройте [официальные Releases](https://github.com/clash-verge-rev/clash-verge-rev/releases). Выберите Latest stable,
   а не AutoBuild/RC.
2. Для обычного Windows 10/11 x64 выберите установщик `.exe` с `x64`; для ARM Windows нужен `arm64`. Если отсутствует
   WebView2, используйте официальный вариант установщика с WebView2.
3. Установите и откройте приложение. Названия пунктов ниже могут немного отличаться в новых версиях.
4. Откройте **Profiles / Профили**. В поле URL вставьте подписку `desktop-windows`, нажмите **Import / Импорт**.
5. Выберите импортированный профиль. Обновление — кнопка обновления его карточки; обновляйте после серверных изменений.
6. Выберите режим **Rule / Правила**. В **Proxies / Прокси** найдите группу `VPN`, выберите `AUTO`. Для резерва
   выберите `FALLBACK` или конкретный узел REALITY/XHTTP/HYSTERIA2/AWG.
7. Для всего интернета устройства включите **TUN Mode**. Установите/включите Service Mode, если приложение предложит;
   запрос прав Windows подтвердите. Подписка не включает TUN сама, чтобы импорт не менял сеть без вашего действия.
8. **System Proxy** удобен для браузеров, но охватывает только программы, которые его используют. Для полного VPN
   рекомендован TUN. Не оставляйте случайно настроенные ручные прокси в других программах.
9. В настройках включите **Launch on startup / Автозапуск** и сохранение состояния TUN, если эта опция есть. После
   перезагрузки проверьте, что TUN действительно включился.
10. Сравните внешний IP до и после включения на доверенном вами сервисе проверки IP; затем откройте несколько сайтов и
    YouTube. IP должен стать адресом VPS.
11. Для полного отключения выключите TUN и System Proxy, затем завершите приложение. Проверьте обычный интернет.

### Windows — AmneziaVPN

Уже установленную AmneziaVPN можно оставить. Скачивать её следует с [официальной страницы](https://amnezia.org/downloads)
. На сервере выполните `kit user link desktop-windows --all`, скопируйте **свою** `vpn://` -ссылку AWG 3.1. В AmneziaVPN
выберите добавление подключения через импорт ключа/буфера обмена, вставьте ссылку, назовите профиль `Мой VPS — AWG31` и
подключитесь. Если импорт 3.1 не поддерживается установленной версией, обновите официальный клиент или импортируйте AWG
classic.

Перед подключением Amnezia отключите TUN/System Proxy Clash. Обычно используйте AUTO в Clash; Amnezia — быстрый
независимый резерв.

## Linux Mint / Ubuntu

1. Из [официальных Releases Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases) скачайте stable
   `.deb`: `amd64` для обычного ПК, `arm64` для ARM. Для Mint/Ubuntu рекомендуем `.deb`; RPM не подходит, AppImage
   оставьте альтернативой.
2. В папке загрузки установите **скачанный файл**, подставив его точное имя:

   ```bash
   sudo apt install ./Clash.Verge_СКАЧАННАЯ_ВЕРСИЯ_amd64.deb
   ```

3. Запустите из меню приложений. Добавьте подписку `desktop-linux` через Profiles → Import и активируйте её.
4. Выберите Rule → `VPN` → `AUTO`. Обновите профиль кнопкой его карточки.
5. Для TUN включите Service Mode/установку службы в настройках и подтвердите polkit-запрос. Затем включите TUN. Если
   разрешения не запрашиваются или служба не работает, проверьте журнал приложения; не запускайте всю графическую
   программу постоянно от root.
6. System Proxy подходит для браузера; для остальных программ нужен TUN. DNS в профиле направляется через VPN; локальные
   `.lan` /`.local` и частные подсети сохраняются напрямую. GUI может переопределять настройки — проверьте итоговый
   режим.
7. Включите автозапуск в настройках, затем проверьте VPN после нового входа в систему. Не запускайте одновременно вторую
   VPN-службу.
8. Отключение: сначала TUN, затем System Proxy, затем выход из приложения. Проверьте сеть и DNS.

AmneziaVPN на Linux: возьмите установщик своей архитектуры с [официального сайта](https://amnezia.org/downloads),
установите по инструкции клиента, импортируйте `vpn://` от `kit user link desktop-linux --all`. Разрешите создание VPN.
Перед подключением отключите Clash.

### После отключения VPN пропал интернет

Сначала проверьте, что оба переключателя Clash выключены и Amnezia тоже отключена. В системных настройках сети проверьте
отсутствие оставшегося ручного прокси. Диагностика без удаления настроек:

```bash
nmcli general status
nmcli connection show --active
ip route
resolvectl status
getent hosts example.com
```

Если `resolvectl` отсутствует, используйте `cat /etc/resolv.conf`. Выход из клиента и повторное подключение Wi-Fi через
обычное меню часто восстанавливают маршрут. Перезапуск NetworkManager на локальном ПК возможен только когда вы готовы
потерять текущую сеть; не делайте это через удалённое подключение. Не удаляйте профили NetworkManager и
`/etc/resolv.conf` вслепую. [Подробная диагностика](manuals/TROUBLESHOOTING.md).

## Android — FlClash

1. Скачайте stable APK из [официальных Releases](https://github.com/chen08209/FlClash/releases). Для большинства
   современных телефонов — `android-arm64-v8a.apk`; `armeabi-v7a` нужен старым 32-bit устройствам, `x86_64` — обычно
   эмулятору.
2. Разрешите установку APK именно вашему браузеру/файловому менеджеру, установите FlClash, затем снимите это разрешение,
   если больше не нужно.
3. На VPS создайте `phone-android`. Скопируйте subscription URL или отсканируйте QR сканером **внутри приложения**, если
   он доступен в вашей версии.
4. В Profiles → Add → URL добавьте подписку, обновите и активируйте профиль.
5. Выберите Rule → `VPN` → `AUTO`. Нажмите кнопку подключения и разрешите Android создать VPN-соединение.
6. Убедитесь, что приложения не исключены через настройки обхода VPN. Для постоянной работы разрешите фоновую работу
   FlClash в настройках батареи; влияние на батарею проверьте сами.
7. Проверьте сайты, YouTube и внешний IP. Переключите Wi-Fi → мобильные данные → Wi-Fi и убедитесь, что новые соединения
   восстановились.
8. Если нет связи, попробуйте FALLBACK и вручную REALITY/XHTTP/HYSTERIA2; после этого отключите FlClash и попробуйте
   AmneziaVPN.

Android — AmneziaVPN: установка с [официального сайта](https://amnezia.org/downloads), импорт `vpn://` от
`kit user link phone-android --all`, имя `Мой VPS — AWG31`, разрешение Android на VPN и подключение. AWG classic тоже
установлен и доступен как дополнительный резерв.

## iPhone / iPad — Happ

[Happ в официальном App Store](https://apps.apple.com/us/app/happ-proxy-utility/id6504287215) указан как бесплатный;
поддерживает REALITY и Hysteria2. Наличие приложения в вашем регионе магазина может отличаться. Основная подписка
отдаётся в родном формате клиента, без неподдерживаемого AWG.

1. Установите Happ. Создайте на VPS `phone-iphone`, скопируйте **его** subscription URL.
2. Нажмите **+** и добавление из буфера/URL подписки. Можно использовать встроенный сканер QR. Обновите подписку.
3. Разрешите добавление VPN-конфигурации iOS. Не импортируйте URL на стороннем сайте.
4. Выберите режим маршрутизации всего интернета; уберите ненужный split routing. Разрешите обход локальной сети, если
   приложение предоставляет этот переключатель.
5. В настройках подписки включите **Пинг при запуске**. Для проверки используйте **Via Proxy**, а не только ICMP:
   отвечающий IP не доказывает исправность VPN.
6. Если ваша версия предлагает автоматический выбор по задержке / Lowest delay, включите его. Иначе нажмите проверку
   доступности и выберите работающий REALITY или XHTTP/Hysteria2 вручную.
7. Нажмите подключение, проверьте сайты и IP. Затем проверьте Wi-Fi → LTE → Wi-Fi. При необходимости переподключите VPN
   из Happ.

**Ограничение:** группы `AUTO` /`FALLBACK` в YAML предназначены для Mihomo; Happ использует собственный механизм выбора
подключения. Его автоподключение по задержке при запуске не равно постоянному контролю всех транспортов. Сервер не
меняйте при смене сети. [Официальная документация пинга](https://www.happ.su/main/ru/faq/ping) и
[настроек приложения](https://www.happ.su/main/ru/dev-docs/app-management).

Для AWG используйте AmneziaVPN: откройте ссылку на App Store с
[официальной страницы загрузки](https://amnezia.org/downloads), импортируйте `vpn://` от
`kit user link phone-iphone --all`, разрешите VPN-профиль. Отключите Happ до подключения Amnezia. Проверяйте поддержку
AWG 3.1 актуальным приложением; classic доступен отдельно.

## macOS

Clash Verge Rev: stable `.dmg` из [официальных Releases](https://github.com/clash-verge-rev/clash-verge-rev/releases),
`arm64` для Apple Silicon или `x64` для Intel. Перенесите приложение в Applications, запустите и подтвердите необходимые
разрешения. Добавьте свою подписку, Rule → `VPN` → AUTO. Для полного VPN включите службу и TUN; System Proxy подходит
только поддерживающим его приложениям. Включите автозапуск и проверьте после перезагрузки. Для отключения выключите TUN и
System Proxy. Резерв — AmneziaVPN с персональной AWG-ссылкой.

## Wi-Fi ↔ мобильная сеть

Сервер перенастраивать не нужно. При изменении адреса телефона текущие соединения могут прерваться: клиент создаёт новые.
AUTO/FALLBACK проверяют транспорт примерно раз в минуту; это не бесшовное сохранение уже открытых TCP-сессий.

Если связь не восстановилась: FALLBACK → REALITY → XHTTP → Hysteria2 → отключить основной VPN → AmneziaVPN / AWG31 → AWG
classic. В Happ начните с проверки через прокси и выбора другого подключения. В чужом Wi-Fi сначала завершите вход на
captive portal без VPN, потом подключайте VPN.

| Режим | Когда выбирать |
|---|---|
| AUTO | обычная работа, выбор доступного транспорта с хорошей задержкой |
| FALLBACK | предпочтение REALITY с приоритетным резервированием |
| REALITY | основной TCP-вариант |
| XHTTP | дополнительный TCP-транспорт; общий nginx и IP остаются общими точками отказа |
| HYSTERIA2 | попробовать при доступном UDP, в том числе на мобильной сети |
| AWG31 | независимый транспорт на 51822/udp, обычно через Amnezia |
| AWG CLASSIC | дополнительный UDP-резерв на 51821/udp |

### Совместимость AWG31 в Mihomo

Поддержка AWG 3.1 появилась в [Mihomo v1.19.30](https://github.com/MetaCubeX/mihomo/releases/tag/v1.19.30). XHTTP
поддерживается современными Mihomo. Версия GUI не равна версии его ядра.

Если User-Agent явно содержит `mihomo/1.19.30` или новее либо `FlClash/0.8.98` или новее, подписка включает AWG31.
Поддержка core официального FlClash 0.8.98 проверена по исходникам его submodule. Если версию ядра определить нельзя,
остаются REALITY/XHTTP/Hysteria2/AWG classic. Это предотвращает импорт неподдерживаемого транспорта. После проверки
версии ядра можно добавить к **той же собственной** subscription URL `?format=mihomo&awg31=1`, обновить профиль и
проверить AWG31. Для клиентов с ядром старее 1.19.22 обновите stable приложение ради XHTTP. Никогда не ставьте alpha
только ради числа узлов.

## Панель 3X-UI через SSH

Панель всегда слушает localhost и не публикуется через nginx. Скопируйте точную команду туннеля из результатов установки
и выполните **на своём компьютере**, оставив окно открытым. Пример с заменяемыми значениями:

```bash
ssh -p SSH_PORT -N -L 8888:127.0.0.1:PANEL_PORT root@SERVER_IP
```

Замените `SSH_PORT` своим SSH-портом (обычно 22), `PANEL_PORT` — портом панели, `SERVER_IP` — адресом VPS. Installer
указывает SSH-порт текущего подключения или единственного обнаруженного SSH-listener; если порт определить нельзя, он
оставляет `SSH_PORT` и выводит предупреждение. При отдельном ключе добавьте `-i путь_к_ключу`. Откройте локальный адрес
панели из результата, например `http://127.0.0.1:8888/СЛУЧАЙНЫЙ_ПУТЬ/`, в браузере и введите сохранённые логин/пароль.
HTTP здесь идёт внутри SSH-туннеля. Если 8888 занят, выберите другой локальный порт и замените его в адресе браузера.

Публичной остаётся только HTTPS-подписка с непредсказуемым путём и персональным токеном. Сертификат IP короткоживущий;
timer проверяет продление дважды в день. Не закрывайте 80/tcp после установки.

## Обслуживание

| Команда | Когда и что делает |
|---|---|
| `kit status` | быстро посмотреть службы, IP, пользователей, протоколы, сертификат, диск/RAM |
| `kit doctor` | при проблемах; диагностика служб, listening ports, HTTPS-подписки, UFW и сертификата |
| `kit version` | узнать версию и источник установки |
| `kit user list` | состояние и суммарный учёт записей устройства |
| `kit user off имя` / `kit user on имя` | отключить / включить устройство |
| `kit user del имя` | удалить его подключение |
| `kit user limit имя --gb 50 --days 30` | установить лимиты; 0 — без ограничений |
| `kit backup` | перед обслуживанием; согласованная SQLite-копия плюс настройки, сертификаты и KIT |
| `kit update check` | прочитать последний stable release этого форка, без установки |
| `kit update` | создать backup и показать инструкцию ручного обновления; код автоматически не применяет |
| `kit harden ssh` | показать безопасный порядок усиления SSH; sshd автоматически не меняет |

Для AWG используется служба панели и встроенная реализация; отдельного `amneziawg.service` обычно нет. Hysteria2
основного KIT работает через Xray, не через отдельный `hysteria-server.service`. Сохранённый standalone
`scripts/hysteria2.sh` — отдельная advanced установка, не запускайте её на занятом 443/udp.

Backup лежит в `/root/kit-backups/`, права файла 0600 и каталога 0700. **Он содержит секреты всех устройств.**
Скопируйте его по SSH в защищённое хранилище вне VPS. Логи, caches и бинарники сервера не включаются. Автоматический
`kit restore` не реализован: [порядок восстановления](manuals/INSTALL.md).

Трафик записей устройства суммируется при выводе `kit user list`. Поскольку двум AWG нужны отдельные записи, лимит
распространяется на каждую такую запись; общий лимит на сумму трафика всех AWG не поддерживается. Для личного
использования обычно оставляйте лимиты отключёнными. Ограничение числа IP также не является надёжным счётчиком физических
устройств.

## Если VPN не работает

1. На VPS: `kit doctor`.
2. На устройстве: другой транспорт или FALLBACK.
3. Сравните Wi-Fi и мобильную сеть.
4. Отключите основной клиент и проверьте AWG через Amnezia.
5. На VPS: `systemctl status x-ui nginx kit-sub --no-pager`.
6. Проверьте `ufw status verbose` и firewall хостера.
7. Проверьте certificate/subscription в `kit doctor`, затем `systemctl list-timers kit-cert-renew.timer`.

| Симптом | Первое действие |
|---|---|
| Подключён, но сайты не открываются | Rule + TUN; проверить DNS и другой узел; `kit doctor` |
| Работает в Wi-Fi, не в LTE | REALITY/XHTTP; проверить ограничение UDP и фоновые разрешения клиента |
| Работает в LTE, не в Wi-Fi | captive portal, firewall сети; попробовать TCP |
| REALITY работает, Hysteria2 нет | проверить 443/udp у хостера и `ss -lunp` на VPS |
| AWG не подключается | свой профиль устройства, нужный порт 51821/51822, версия Amnezia, другой AWG |
| Subscription не обновляется | проверить часы, сертификат и URL; `kit doctor`, состояние kit-sub |
| Linux потерял интернет | выключить оба режима VPN; `nmcli`, `ip route`, `getent hosts` |
| После перезагрузки VPS нет VPN | `systemctl is-enabled x-ui nginx kit-sub`; `kit doctor` |
| YouTube медленно | сравнить узлы, проверить packet loss/нагрузку VPS, снизить качество для сравнения |

Конкретные команды для каждого случая — в [TROUBLESHOOTING.md](manuals/TROUBLESHOOTING.md). Не публикуйте сырые журналы
без удаления секретов.

## Проверить скорость

Проверьте привычные сайты, старт и перемотку YouTube, задержку и потери, ваши конкретные приложения. Speedtest —
дополнительная метрика: хороший результат не доказывает качество маршрута до другого сервиса.

На ПК до/после VPN: `ping -c 10 example.com` на Linux/macOS или `ping -n 10 example.com` на Windows; ICMP может идти
иначе или блокироваться. Для HTTPS на Linux/macOS:

```bash
curl -I --max-time 15 https://example.com
```

На VPS проверьте `free -h`, `df -h /`, `uptime`. Сравнивайте в одинаковой сети и с одинаковым видео. AUTO выбирает по
задержке контрольного URL, поэтому самый быстрый для большого скачивания узел иногда стоит выбрать вручную.
